# אנגלית לסיגל — Expo app

A native (Expo / React Native) wrapper around the "English for Sigal" game.
It shows the live game inside a full-screen WebView, so any new levels added
to the website appear automatically without rebuilding the app.

- Game URL it loads: `https://razonjewelry.github.io/flappy-bird/sigal-english.html`
- App name: **אנגלית לסיגל**
- Android package / iOS bundle id: `com.razon.sigalenglish`

## Prerequisites
- [Node.js](https://nodejs.org) 18+ and npm
- An [Expo](https://expo.dev) account (free) for cloud builds
- `npm install -g eas-cli` (for building the APK)

## 1. Install dependencies
```bash
cd sigal-app
npm install
# make sure native deps match the Expo SDK:
npx expo install react-native-webview expo-status-bar
```

## 2. Try it instantly on your phone (no build)
```bash
npx expo start
```
Install the **Expo Go** app on the phone, then scan the QR code. The game opens
inside Expo Go — good for a quick check.

## 3. Build a real installable Android app (APK)
```bash
eas login            # first time only
eas build:configure  # first time only — creates eas.json
eas build -p android --profile preview
```
- `--profile preview` produces an **APK** you can download and install directly
  (send the link to the phone, tap to install — allow "install from unknown
  sources" if asked).
- For Google Play, use `--profile production` (produces an `.aab`).

## 4. iPhone (optional)
```bash
eas build -p ios --profile preview
```
Requires an Apple Developer account ($99/yr) to install on real devices.

## Regenerating the icons
The icons in `assets/` were generated by a small script (teal background +
white flower). To change them:
```bash
cd assets
node gen-icons.js
```

## Notes
- The app needs internet on first open; after that the website's offline cache
  keeps it working without a connection.
- Because it loads the live site, updating the game = just push to the website;
  the app updates itself. You only rebuild the APK to change the icon, name, or
  native settings.
