# שלושת המוצרים המרכזיים: טקסטים מוכנים

מה שמסומן ב-[סוגריים מרובעים] צריך לבדוק או להשלים לפני שמעלים: משקל, אורך שרשרת, מחיר ומידות.
**לא משנים את כתובת העמוד.** מעדכנים רק כותרת, תיאור וטקסט.

## 1. טבעת חיבוקי: זהב 14K
עמוד: https://www.razon.co.il/טבעת-חיבוקי-חיבוק/

**למה לשנות:** הכותרת היום היא "טבעת חיבוקי - חיבוק". רוב האנשים מחפשים **"טבעת חיבוק"** או **"טבעת ידיים מחבקות"**, ומוסיפים לחיפוש "זהב". צריך שכל המילים האלה יופיעו בכותרת.

**כותרת SEO (Title):**
```
טבעת חיבוק זהב 14K, שתי ידיים מחבקות | רצון תכשיטים
```

**תיאור (Meta description):**
```
טבעת חיבוק מזהב 14K אמיתי: שתי ידיים עדינות שמחבקות את האצבע. מתנה מרגשת לאמא, לבת זוג או לחברה. התאמת מידה חינם, אחריות לשנה ומשלוח חינם מעל 500 ₪.
```

**שם המוצר בעמוד (H1):**
```
טבעת חיבוקי: טבעת חיבוק מזהב 14K
```

**תיאור המוצר בעמוד:**
> שתי ידיים קטנות שעוטפות את האצבע בחיבוק. זה כל הרעיון, וזו בדיוק הסיבה שלקוחות חוזרים לקנות את הטבעת הזאת כמתנה.
>
> הטבעת עשויה זהב 14K אמיתי [צהוב / לבן / אדום: לציין מה יש במלאי], ומלוטשת ביד בסדנה שלנו בפתח תקווה. היא עדינה מספיק לענידה יומיומית, ובולטת מספיק כדי שישאלו אותך מאיפה היא.
>
> **למי זה מתאים:** מתנה לאמא, לבת זוג, לחברה הכי טובה, לבת שעוזבת את הבית, או סתם חיבוק למישהי שצריכה אותו.

**פרטים (טבלה בעמוד):**

| חומר | זהב 14K (585) |
| צבע | [צהוב / לבן / אדום] |
| משקל | [__ גרם] |
| רוחב | [__ מ"מ] |
| מידות | [__ עד __]. התאמת מידה חינם |
| אחריות | שנה |

**טקסט חלופי לתמונות (alt):**


**תיאור:**
```

```

**שם המוצר (H1):**
```
שרשרת בית המקדש מכסף 925
```

## 3. שרשרת מגן דוד: כסף 925

**כותרת SEO:**

**תיאור:**

## עמוד מתנות שמרכז את כולם
כדאי לפתוח עמוד **"מתנה לגיוס"** (תכשיטים לחיילים ולחיילות). זה חיפוש עם כוונת קנייה גבוהה, ושתי השרשראות מתאימות לו בדיוק.
- כותרת: `מתנה לגיוס: שרשראות כסף וזהב לחיילים ולחיילות | רצון תכשיטים`
- בעמוד: מגן דוד, בית המקדש, ועוד 4 עד 6 שרשראות ותליונים שיש במלאי.
