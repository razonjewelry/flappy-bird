# המשימות שלנו — אור וזיו

אפליקציית משימות משותפת ל-React Native / Expo. המשימות נשמרות בענן
ומסונכרנות בין המכשירים בזמן אמת.

בנוי על **Expo SDK 57** ו-**Firebase 12**.

## הרצה

```bash
npm install
npx expo start
```

יופיע קוד QR. בטלפון מתקינים **Expo Go** מהחנות וסורקים:

- **אנדרואיד** — סורקים ישירות מתוך Expo Go
- **אייפון** — סורקים עם אפליקציית המצלמה הרגילה, והיא תפתח את Expo Go

שני המכשירים והמחשב צריכים להיות על אותה רשת Wi-Fi. אם לא — מריצים
`npx expo start --tunnel`.

## Firebase

הפרויקט כבר מחובר ל-`or-ziv-tasks`. אלה ההגדרות שנעשו פעם אחת בקונסולה:

| מה | איפה |
|---|---|
| Firestore Database | `eur3 (europe-west)`, מסד `(default)` |
| התחברות אנונימית | Authentication → Sign-in method → Anonymous → Enabled |
| חוקי אבטחה | התוכן של `firestore.rules` פורסם ללשונית Rules |

אם משנים את `firestore.rules` כאן, צריך להעתיק את התוכן שוב לקונסולה
וללחוץ Publish. הקובץ בריפו הוא עותק לעיון; הוא לא נפרס אוטומטית.

### על המפתחות ב-src/firebaseConfig.js

הערכים האלה אינם סוד וגם לא אמורים להיות — בכל אפליקציית Web או מובייל הם
מגיעים ממילא למכשיר של המשתמש. מה שמגן על הנתונים הוא חוקי האבטחה.

## שימוש

| פעולה | איך |
|---|---|
| הוספת משימה | כותבים למטה ולוחצים על כפתור השליחה |
| סימון שבוצע | לוחצים על העיגול |
| דחייה לאחר כך | לוחצים על אייקון השעון המעורר |
| צפייה בדחויים | כפתור "דחויים" בראש המסך |
| מחיקה | לחיצה ארוכה על המשימה |
| החלפת משתמש | לוחצים על השם בראש המסך |

## מבנה הקוד

```
index.js                    נקודת הכניסה
App.js                      ניתוב בין המסכים וטעינה ראשונית
src/firebaseConfig.js       מפתחות הפרויקט
src/lib/firebase.js         אתחול Firebase והתחברות אנונימית
src/lib/tasks.js            קריאה וכתיבה של משימות ב-Firestore
src/lib/useTasks.js         הוק שמחזיק את הרשימה המסונכרנת
src/lib/offlineCache.js     עותק מקומי להצגה מיידית בפתיחה
src/lib/users.js            הגדרת אור וזיו ושמירת המשתמש הנוכחי
src/screens/                מסכי האפליקציה
firestore.rules             חוקי האבטחה (עותק לעיון)
```

## מגבלות ידועות

- **שני משתמשים קבועים.** אור וזיו מוגדרים ב-`src/lib/users.js` וגם בחוקי
  האבטחה. הוספת אדם שלישי דורשת עריכה בשני המקומות.
- **אין התחברות אמיתית.** ההתחברות אנונימית, ולכן כל מי שמתקין את
  האפליקציה יכול לבחור להיות אור או זיו. מכיוון שהריפו ציבורי, מי שימצא
  אותו יוכל להגיע לנתונים. לאפליקציה פרטית של שניים זה סביר; להקשחה צריך
  להחליף להתחברות עם מייל וסיסמה ולנעול את החוקים לשני מזהי המשתמש.
- **המטמון המקומי הוא לתצוגה בלבד.** ה-SDK של Firebase ל-JavaScript לא
  שומר מטמון קבוע ב-React Native, ולכן יש כאן עותק משלנו ב-AsyncStorage.
  משימה שנוצרה בלי אינטרנט תישלח כשהרשת תחזור, כל עוד האפליקציה לא נסגרה
  בינתיים.
