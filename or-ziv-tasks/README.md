# המשימות שלנו — אור וזיו

אפליקציית משימות משותפת ל-React Native / Expo. המשימות נשמרות בענן ומסונכרנות
בין המכשירים בזמן אמת.

## מה השתנה מהגרסה הקודמת

הגרסה הראשונה החזיקה את המשימות ב-`useState` בלבד. זה אומר שכל אחד ראה רשימה
מקומית משלו, וסגירת האפליקציה מחקה הכול. הגרסה הזו מחליפה את זה ב-Firestore:

- **סנכרון בזמן אמת** — משימה שנוספת אצל אחד מופיעה אצל השני תוך שנייה, בלי לרענן.
- **שמירה קבועה** — הנתונים בענן, אז הם שורדים סגירה, החלפת מכשיר והתקנה מחדש.
- **בחירת משתמש חד-פעמית** — במקום כפתור "Acting as" לבדיקות, בוחרים פעם אחת
  מי אתם והבחירה נשמרת במכשיר.
- **עבודה במצב לא מקוון** — הרשימה האחרונה מוצגת גם בלי אינטרנט, ושינויים
  שנעשו במצב כזה נשלחים כשהרשת חוזרת.

## התקנה

```bash
cd or-ziv-tasks
npm install
npx expo start
```

סורקים את ה-QR עם אפליקציית Expo Go בטלפון.

אם אתם משלבים את הקוד בפרויקט Expo קיים, מספיק להתקין את שתי התלויות החדשות:

```bash
npx expo install firebase @react-native-async-storage/async-storage
```

## חיבור ל-Firebase (חד-פעמי)

בלי השלב הזה האפליקציה תעלה ותציג מסך הסבר במקום את הפיד.

1. **פרויקט חדש** — [console.firebase.google.com](https://console.firebase.google.com)
   → Add project. אפשר לדלג על Google Analytics.
2. **מסד נתונים** — Build → Firestore Database → Create database. בוחרים מיקום
   (למשל `europe-west3`) ומתחילים ב-production mode; את החוקים נחליף בסעיף 5.
3. **התחברות** — Build → Authentication → Get started → Sign-in method →
   מפעילים את **Anonymous**. אין מסך התחברות באפליקציה; זה רק נותן לכל מכשיר
   זהות מול Firebase כדי שאפשר יהיה לנעול את הנתונים.
4. **מפתחות** — ⚙️ Project settings → Your apps → אייקון ה-Web (`</>`) →
   רושמים אפליקציה ומעתיקים את אובייקט `firebaseConfig` לתוך
   `src/firebaseConfig.js`.
5. **חוקי אבטחה** — מעתיקים את התוכן של `firestore.rules` ללשונית Rules
   ב-Firestore ולוחצים Publish.

### על המפתחות

הערכים ב-`src/firebaseConfig.js` אינם סוד וגם לא אמורים להיות. בכל אפליקציית
Web או מובייל הם מגיעים ממילא למכשיר של המשתמש. מה שבאמת מגן על הנתונים הוא
חוקי האבטחה שבסעיף 5 — לכן אל תדלגו עליהם.

## שימוש

| פעולה | איך |
|---|---|
| הוספת משימה | כותבים למטה ולוחצים על כפתור השליחה |
| סימון שבוצע | לוחצים על העיגול משמאל |

## מבנה הקוד

```
App.js                      ניתוב בין המסכים וטעינה ראשונית
src/firebaseConfig.js       המפתחות שלכם (למלא ידנית)
src/lib/firebase.js         אתחול Firebase והתחברות אנונימית
src/lib/tasks.js            קריאה וכתיבה של משימות ב-Firestore
src/lib/useTasks.js         הוק שמחזיק את הרשימה המסונכרנת
src/lib/offlineCache.js     עותק מקומי להצגה מיידית בפתיחה
src/lib/users.js            הגדרת אור וזיו ושמירת המשתמש הנוכחי
src/screens/                מסכי האפליקציה
firestore.rules             חוקי האבטחה
```

## מגבלות ידועות

- **שני משתמשים קבועים.** אור וזיו מוגדרים בקוד ב-`src/lib/users.js` ובחוקי
  האבטחה. הוספת אדם שלישי דורשת עריכה בשני המקומות.
- **אין התחברות אמיתית.** כל מי שמתקין את האפליקציה יכול לבחור להיות אור או
  זיו. לאפליקציה פרטית של שניים זה בסדר; אם זה יפריע, צריך להחליף את
  ההתחברות האנונימית בהתחברות עם מייל.
- **המטמון המקומי הוא לתצוגה בלבד.** ה-SDK של Firebase ל-JavaScript לא שומר
  מטמון קבוע ב-React Native, ולכן יש כאן עותק משלנו ב-AsyncStorage. משימה
  שנוצרה בלי אינטרנט תישלח כשהרשת תחזור, כל עוד האפליקציה לא נסגרה בינתיים.
